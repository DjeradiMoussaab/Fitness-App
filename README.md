## The SEPHORA Application

SEPHORA is an iOS application written in Swift 5. It is a solution to the SEPHORA test.

- The application is a **multi-screen** app.
- The application must contain a login screen.
- The application is developped using a reactive programming approach with Apple's Nativ Framework **Combine**
- The implementation is based on clean architecture pattern with a modulare network layer.
- Clean, structured and reusable code.
